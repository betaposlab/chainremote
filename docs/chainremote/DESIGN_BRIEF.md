# ChainRemote 본사 앱 디자인 의뢰서 (Claude Design 용)

> 작성: 2026-05-27. 의뢰 대상: Claude Design.
> 결과물: 메인 화면 / 상단바 / 설정 페이지 시안 — Figma 또는 고해상도 PNG.

## 1. 회사 / 제품 한 줄

- **회사**: 베타포스랩 (betaposlab) — POS/키오스크 운영하는 식당·소매 거래처 200+ 곳을 원격 A/S 하는 한국 B2B 솔루션 회사.
- **제품**: **ChainRemote (체인리모트)** — 한국 중소 VAN 대리점용 원격지원 솔루션.
- **포지셔닝**: 코이노 AnySupport (월 10만원/seat) 의 1/3~1/5 가격(월 2~3만/대리점) 대체재. 50개 대리점 판매가 목표 — 시장 전체 먹겠다는 게 아니라 **"간단하고 빠른 한국 SaaS"** 로 소규모 대리점만.

## 2. 톤 & 무드

**참고 타깃 (한국 B2B SaaS 톤)**:
- 토스(Toss) — 부드러운 그림자, 둥근 모서리, 정돈된 여백, 친절한 마이크로카피
- 카카오뱅크 — 흰 베이스 + 노란 포인트, 깔끔한 정보 위계
- 슬랙 / Linear — 사이드바 + 메인 콘텐츠 구조의 정석

**피해야 할 톤**:
- ❌ 게이밍 / 다크 사이버 / 네온 (TeamViewer, AnyDesk 의 옛 톤)
- ❌ 회색 일변도 / 윈도우 95 느낌 (현 RustDesk 외관)
- ❌ 과한 일러스트 / 카툰 캐릭터

**원칙: 간결함이 곧 차별화.**
- Chang 의 핵심 가치 → "거래처는 받은 .exe 2번 클릭 + 비번 1번. 끝." 이 UX 가치를 본사 앱 디자인에서도 동일하게 드러낼 것.
- 코이노 4단계 → 우리 2단계. 화면도 코이노의 정보 과부하 ↔ 우리의 시원시원함 대비.

## 3. RustDesk 외관과의 차별화

⚠️ **이 항목이 가장 중요.** 우리 앱은 RustDesk 포크라서 백엔드는 같지만 **외관이 RustDesk 와 같으면 자체 SW 로 안 보임.** 시각적으로 즉시 "다른 앱이구나" 가 느껴져야 함.

| 항목 | RustDesk 현재 | ChainRemote 지향 |
|------|---------------|------------------|
| 컬러 | 짙은 파랑 + 회색 | 흰 베이스 + 한 포인트 컬러 (제안: 따뜻한 코랄/오렌지 or 차분한 블루그린) |
| 사이드바 | 좁은 아이콘 바 | 텍스트+아이콘 친절한 사이드바 (토스 스타일) |
| 둥글기 | 8px | 12~16px (소프트) |
| 그림자 | 거의 없음 | 부드럽고 옅은 elevation |
| 폰트 | Roboto 기본 | Pretendard 또는 Spoqa Han Sans Neo (한글 가독성) |
| 비기능 영역 | RustDesk 로고 + 빈 공간 | ChainRemote 로고 + 본사 직원 자기 9자리 ID 칩 |

## 4. 화면 명세

### 4-A. 메인 (홈)

**진입 시 디폴트 탭 = 즐겨찾기.** (이미 코드 박힘 — `peer_tab_model.dart::_currentTab=fav`)

**구성**:
1. **상단바** — 별도 명세 (4-B)
2. **탭 영역** — "즐겨찾기" / "최근 세션" 2개 (현재 코드 상태). 토스 스타일 underline tab.
3. **거래처 카드 그리드** — 한 행에 3~4개. 카드 내용:
   - 거래처 이름 (큰 글씨, ex. "바다양푼이 동태찜")
   - 그 아래 작게: 9자리 remote ID
   - 우상단: 상태 dot (녹색=10분 내 heartbeat, 주황=2시간 내, 빨강=하루 이상, 회색=미보고)
   - 우상단: `v1.3.2` 버전 칩
   - 메인 CTA: 카드 전체 클릭 = 1클릭 원격 시작
   - 우클릭 메뉴: 즐겨찾기 해제 / 정보 / 비밀번호 재입력

**왜 카드?** 코이노/AnyDesk 모두 ID 리스트 텍스트 줄. 우리는 **거래처 단위로 시각 인지**가 빠르게 일어나야 함 (대리점 사장이 "어제 갔던 그 양푼이 집!" 으로 카드 한 번에 인지).

### 4-B. 상단바

- **좌측**: ChainRemote 로고 + "ChainRemote" wordmark
- **중앙**: 현재 화면 타이틀 (예: "홈") — 옵션, 미니멀하게
- **우측**:
  - 본인 9자리 ID 칩 (`123 456 789` 3-3-3 포맷) — 클릭 시 복사, "복사됨!" 토스트
  - 알림 종 (선택)
  - 사용자 프로필 (chang / jaesung 표시 + 로그아웃)

ID 칩이 차별화 포인트 중 하나 — 본사 직원이 자기 ID 를 거래처 카드에 ChainGo 처럼 알려주거나 영업 시연에서 즉시 띄울 수 있게.

### 4-C. 설정

**탭 구조** (좌측 세로 탭):
1. **일반** — 시작 시 실행, 트레이 표시, 언어, 테마(다크/라이트/시스템)
2. **계정** — chang / jaesung 로그인 정보, 로그아웃, 관리 패널 바로가기는 제거됨
3. **세션** — 기본 화질, 코덱(자동/H264/H265), 클립보드 공유
4. **업데이트** — 현재 버전, "업데이트 확인" 버튼, 최근 폴링 시각
5. **정보** — ChainRemote v1.3.x, RustDesk fork 명시 + AGPL v3, 소스 링크, 베타포스랩 카피라이트

각 탭은 카드형 그룹화. 토스의 "설정" 탭 톤. **윈도우 옛 컨트롤 패널 스타일 절대 X.**

## 5. 기술 제약

- **프레임워크**: Flutter Desktop (Mac + Windows). 디자인 시안은 PNG 또는 Figma. 토큰화된 디자인 시스템 있으면 좋음.
- **해상도**: Mac (Retina 16" 베이스, 1512×982 logical), Windows (FHD 1920×1080 베이스).
- **다크모드**: 라이트 우선. 다크는 v2 작업.
- **i18n**: 한국어 only (당장은). 폰트는 Pretendard.
- **아이콘 셋**: Lucide / Phosphor / Material 중 하나로 통일 제안.

## 6. 산출물

1. **메인 (홈) 화면** — 라이트 모드 시안
2. **상단바** — 호버/클릭 상태 포함
3. **설정 페이지** — 각 탭 1장씩 (총 5장)
4. **컬러 팔레트** + **타이포 스케일** + **버튼/카드 컴포넌트 시안**
5. (보너스) 로고 리파인 제안 — 현 ChainRemote 로고가 단순 텍스트인데 심볼+워드마크 조합으로 정리 제안 받고 싶음

## 7. 일정 / 우선순위

- 1차 시안: 메인 + 상단바 (1주 안)
- 2차 시안: 설정 5탭 (1주)
- 의사결정자: Chang (대표) 단독. 빠른 회전 가능.

## 8. 절대 변경 금지

- **탭 디폴트 = 즐겨찾기** (코드/DB 구조 이미 고정)
- **상단바 본인 ID 칩** 필수
- **카드 클릭 = 1클릭 원격 시작** 필수
- 거래처 즐겨찾기는 **본인 것만** 보임 (관리 패널이 전체뷰. 본사 앱은 개인뷰)
