Why ChainRemote

복잡한 원격 접속, 이제 그만

방문·세션번호·다운로드·실행으로 이어지던 번거로운 접속 절차 없이, 거래처도 본사도 클릭 한 번으로 끝납니다.

거래처는 클릭 한 번

설치는 방문 시 한 번이면 끝. 거래처는 원격이 올 때 '수락' 버튼만 누르면 됩니다 — IT를 몰라도 누구나 가능합니다.

본사도 클릭 한 번

즐겨찾기에서 거래처를 누르면 바로 원격이 시작됩니다. 세션 번호를 받아 적을 필요가 없습니다.

거래처가 통제

매 연결마다 거래처의 '수락'이 있어야 화면이 열립니다. 무단 접속 걱정 없이 안심하고 쓸 수 있습니다.

거래처는 무제한

거래처(가맹점)는 몇 곳이든 무제한으로 등록할 수 있습니다. 사용하는 계정(아이디) 수만큼만 합리적으로 과금됩니다.

구형 포스도 그대로

포스는 한 번 들이면 십 년을 씁니다. Windows 7과 32비트 임베디드까지 지원하므로, 기기가 낡았다는 이유로 못 받는 지원은 없습니다.

알아서 최신으로

거래처 프로그램은 우리가 원격으로 올려 드립니다. 매장이 200곳이어도 한 번에, 사장님이 아무것도 누르지 않아도 조용히 최신 상태가 됩니다.

Only ChainRemote

디스크가 꽉 차기 전에,
우리가 먼저 압니다

예전 포스는 디스크가 찰 일이 없었습니다. 포스 프로그램 하나에 카드 결제 데몬이 전부였으니까요. 배달이 늘면서 달라졌습니다. 주문 접수 앱에 배달대행 프로그램까지, 포스 한 대에 상주 프로그램이 서너 개씩 붙었습니다.

이런 앱들은 대개 브라우저 엔진을 통째로 안고 있어 한 개가 수백 MB이고, 사장님이 모르는 사이 백그라운드로 자동 업데이트하면서 받은 설치 파일과 이전 버전 폴더를 그대로 남깁니다. 여기에 윈도우 업데이트 잔재와 매일 쌓이는 주문·영수증 로그가 더해집니다. 지우는 사람이 없으면 쌓이기만 하는데, 포스·키오스크는 큰 디스크를 쓰지 않습니다. 가득 차는 그날, 결제와 주문이 멈춥니다.

ChainRemote는 각 거래처의 남은 용량을 항상 지켜보다가, 위험하면 미리 알리고 원격 접속 없이도 정리합니다 — 장애가 나기 전에 손쓰는, 우리만의 기능입니다.

  • 모든 거래처의 디스크 여유를 자동 보고
  • 위험 수준에 닿으면 경고 배지
  • 임시파일·휴지통을 원격 없이 버튼 하나로 정리

꺼놓은 방화벽,
어느 날 조용히 되살아납니다

한 매장에 포스가 두 대 이상이면 메인 포스와 서브 포스가 주문·매출·주방 프린터를 실시간으로 주고받습니다. 윈도우 방화벽이 이 통신을 막기 때문에, 포스 업계는 설치할 때 방화벽을 해제해 두는 게 관례입니다.

문제는 그 다음입니다 — 방화벽을 꺼 두면 윈도우가 화면 구석에 "방화벽이 꺼져 있습니다" 경고를 계속 띄웁니다. 그 알림에 [켜기] 버튼이 붙어 있어서, 사장님이 거슬리는 알림을 없애려다 무심코 한 번 누르면 그 자리에서 방화벽이 되살아납니다. 윈도우 업데이트가 스스로 되돌려 놓기도 합니다.

그날부터 서브 포스 주문이 메인으로 넘어가지 않는데 화면에는 아무 안내가 없습니다. 누른 사람도 그게 원인인 줄 모릅니다. 장사 중에 원인도 모른 채 전화부터 받게 됩니다.

  • 누르게 만드는 '방화벽 꺼짐' 알림부터 정리 — 손댈 일이 없어집니다
  • 에이전트가 90초마다 방화벽 상태를 감시
  • 그래도 켜지면 90초 안에 원래대로 — 사람이 몰라도 스스로 복구
  • 필요한 매장에만 — 거래처별로 켜고 끄는 관제

카드가 안 긁히는데,
미리 알 방법이 없습니다

포스의 카드 결제는 VAN 사가 준 데몬 프로그램이 떠 있어야 성립합니다. 이게 멈춰도 평소엔 아무 예고가 없습니다. 카드를 긁는 순간에야 승인 오류가 뜹니다 — 그것도 손님 앞에서.

그래서 발견되는 시점이 늘 같습니다. 계산은 밀리고, 사장님은 원인도 모른 채 전화부터 겁니다.

눈으로는 구분도 안 됩니다. 트레이 아이콘이 남아 있는데 마우스를 대면 사라지기도 하고, 프로그램은 멀쩡히 떠 있는데 데몬만 멈춰 있기도 합니다. 겉모습만 봐서는 어느 쪽인지 알 수 없습니다.

  • 결제가 오가는 중에는 건드리지 않습니다
  • 리더기 케이블처럼 되살려도 안 낫는 고장은 그만 시도하고 패널로 알립니다
  • VAN 사는 매장마다 다릅니다 — 거래처별로 켜고 끄는 관제

How it works

설치 한 번, 그 다음엔 '수락'만

설치는 단 한 번. 그 다음부터는 원격이 올 때 '수락'만 누르면 됩니다.

1

방문 시 한 번 설치

방문 시 ChainRemote Agent를 한 번 설치합니다. 거래처는 손댈 것이 없습니다.

2

ID 자동 등록

설치하면 그 PC 전용 접속 ID가 자동으로 만들어져 본사 관리 패널에 등록됩니다. 거래처가 따로 할 일은 없습니다.

3

원격이 오면 '수락' 클릭

본사가 접속하면 작은 카드가 뜹니다. 거래처는 '수락'만 누르면 끝 — 거래처가 하는 유일한 동작입니다.

본사 직원은 설치 → 로그인 → 즐겨찾기에서 거래처 클릭 = 바로 원격 시작

처음 실행할 때 Windows가 "확인되지 않은 게시자" 안내를 띄울 수 있습니다. "추가 정보 → 실행"을 한 번 눌러주시면 됩니다. (정식 코드 서명 적용 전까지의 일시적 안내입니다.)
