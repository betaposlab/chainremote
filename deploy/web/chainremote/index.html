WHY CHAINREMOTE

복잡한 원격 접속, 이제 그만

방문·세션번호·다운로드·실행으로 이어지던 번거로운 접속 절차 없이, 거래처도 본사도 클릭 한 번으로 끝납니다.

거래처는 클릭 한 번

설치는 방문 시 한 번이면 끝. 거래처는 원격이 올 때 '수락' 버튼만 누르면 됩니다 — IT를 몰라도 누구나 가능합니다.

본사도 클릭 한 번

즐겨찾기에서 거래처를 누르면 바로 원격이 시작됩니다. 세션 번호를 받아 적을 필요가 없습니다.

거래처가 통제

매 연결마다 거래처의 '수락'이 있어야 화면이 열립니다. 무단 접속 걱정 없이 안심하고 쓸 수 있습니다.

거래처는 무제한

거래처(가맹점)는 몇 곳이든 무제한으로 등록할 수 있습니다. 사용하는 계정(아이디) 수만큼만 합리적으로 과금됩니다.

HOW IT WORKS

설치 한 번, 그 다음엔 '수락'만

설치는 단 한 번. 그 다음부터는 원격이 올 때 '수락'만 누르면 됩니다.

1

방문 시 한 번 설치

방문 시 ChainRemote Agent를 한 번 설치합니다. 거래처는 손댈 것이 없습니다.

2

ID 자동 등록

설치하면 9자리 ID가 생성돼 본사 관리 패널에 등록됩니다. 거래처가 따로 할 일은 없습니다.

3

원격이 오면 '수락' 클릭

본사가 접속하면 작은 카드가 뜹니다. 거래처는 '수락'만 누르면 끝 — 거래처가 하는 유일한 동작입니다.

본사 직원은 설치 → 로그인 → 즐겨찾기에서 거래처 클릭 = 바로 원격 시작

처음 실행할 때 Windows가 "확인되지 않은 게시자" 안내를 띄울 수 있습니다. "추가 정보 → 실행"을 한 번 눌러주시면 됩니다. (정식 코드 서명 적용 전까지의 일시적 안내입니다.)
